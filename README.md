# Toronto & Vancouver Crime Analysis

## Overview

This project explores crime patterns and trends in Toronto and Vancouver using publicly available police open data. The analysis was conducted in **Jupyter Notebook (EDA)** and finalized as a **Power BI dashboard**, which is shared here as a **PDF export** for easy viewing and portability.

## Objectives

The goal of this project is to answer key analytical questions about urban crime:

* How have total crime volumes changed over time?
* Which major crime categories (MCI) are most prevalent?
* Is there seasonality in crime by month or day of week?
* What times of day see the highest concentration of incidents?
* How do crime patterns vary by neighbourhood, premises type, and location?

## Data

* **Source:** Police open data (Toronto & Vancouver)
* **Granularity:** Incident-level records (~450k+ rows for Toronto alone)
* **Key Features:**

  * Temporal variables (year, month, day, hour, weekday)
  * Crime classifications (MCI category, offence type)
  * Spatial indicators (neighbourhoods, divisions, latitude/longitude)
  * Contextual attributes (premises type, location type)

## Methods & Tools

* **Python (Jupyter Notebook):**

  * Data cleaning and validation (missing values, type checks)
  * Descriptive statistics and aggregation
  * Temporal and categorical trend analysis
  * Visualization using Matplotlib and Seaborn
* **Power BI:**

  * Interactive dashboards for crime trends
  * Filters by time, crime category, neighbourhood, and premises type
  * High-level visual storytelling for non-technical audiences

## Key Insights

* Crime volume shows clear **temporal patterns**, with variation by year and season.
* Certain **crime categories dominate overall counts**, while others show sharper time-of-day or location-specific spikes.
* Crime is **not evenly distributed** across neighbourhoods or premises types, highlighting spatial concentration effects.
* Distinct patterns emerge by **hour of day and day of week**, useful for resource planning and public safety analysis.

## Deliverables

* Jupyter Notebook with full EDA workflow and visualizations
* Power BI dashboard for interactive exploration and reporting

* Work with large, real-world public datasets
* Translate exploratory analysis into stakeholder-ready dashboards
